# Assistente de Voz em Python #

Este é um projeto simples de assistente de voz pra praticar inglês, ele escuta o que você diz, converte sua fala em texto e responde com uma voz sintetizada.
 
##  O que ele faz ##

- Escuta comandos pelo microfone
- Converte a fala em texto usando a API do Google
- Escreve o que foi falado
- Traduz a fala
- e Repete a pronuncia correta

##  Bibliotecas Utlizadas ##

-  speech_recognition - reconhecimento de fala, com suporte para diversos mecanismos e APIs, online e offline
      pip install SpeechRecognition
- pyttsx3 - Conversão de texto em fala sintetizada
      pip install pyttsx3
- time - biblioteca padrão do python usada para controlar o tempo, delay, horários, cronômetros etc...

Python 3.11.2
